# AI4Love Knowledge Base

Portable source of truth for AI4Love positioning, personas, agents, doctrine, and product context. Plain markdown. Loads locally or in any LLM.

## How to use this

- **Load one folder at a time.** Each top-level folder is a topic. Drop the folder's README into a chat to get an index, then load specific files.
- **Drop a single file into any LLM.** Each file is self-contained enough to reason about on its own.
- **Edit in any text editor.** No vendor lock-in. Markdown is the source format.
